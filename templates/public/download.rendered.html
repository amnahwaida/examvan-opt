Pusat Unduhan EXAMVAN

Unduh berkas instalasi client ujian terproteksi untuk tipe perangkat Android, Windows, maupun Linux.

Instalasi Client Android

Pilih versi aplikasi yang sesuai dengan kebutuhan perangkat

Belum ada installer Android (APK) yang tersedia di sistem.

Panduan Aktivasi Android

Untuk Siswa — Instalasi Normal
1
Unduh Aplikasi Ketuk tombol Unduh APK di kartu unduhan di atas, lalu tunggu hingga unduhan selesai.
2
Izinkan Pemasangan dari Sumber Tidak Dikenal Buka file APK hasil unduhan. Jika muncul peringatan keamanan, pilih izinkan pemasangan dari sumber tidak dikenal untuk aplikasi browser yang Anda pakai. Lokasi menu pengaturan ini berbeda-beda tergantung merk HP — buka daftar di bawah sesuai merk perangkatmu:
Samsung Pengaturan → Aplikasi → ketuk titik tiga (⋮) di kanan atas → Akses khusus → Instal aplikasi tak dikenal → pilih browser (Chrome/dll.) → aktifkan Izinkan dari sumber ini.
Xiaomi / Redmi / POCO Pengaturan → Sandi & keamanan (atau Privasi) → Kontrol lebih lanjut → Instal aplikasi tak dikenal → pilih browser → aktifkan izinnya. Jika diminta, masuk ke akun Mi dan centang "Saya menyadari risikonya".
vivo / iQOO Pengaturan → Aplikasi → Instal aplikasi tak dikenal (atau lewat Manajer i → Izin) → pilih browser → aktifkan Izinkan menginstal aplikasi tak dikenal.
Oppo / Realme / OnePlus Pengaturan → Pengaturan tambahan → Instal aplikasi tak dikenal (atau Perangkat & aplikasi → akses khusus) → pilih browser → aktifkan Izinkan instalasi aplikasi.
3
Masukkan Alamat Server & Token Ujian Buka aplikasi EXAMVAN, lalu isi kolom alamat server dan Token Ujian 8-karakter. Alamat server & token diberikan oleh pengawas atau panitia ujian saat ujian dimulai — jangan menebak-nebak.
Contoh format alamat server: http://192.168.1.10:8080
Tips Pemecahan Masalah
  • Uninstall Versi Lama: Hapus versi lawas terlebih dahulu sebelum memasang yang baru untuk mencegah konflik sertifikat digital.
  • Play Protect: Jika muncul penolakan, pilih "Detail" lalu klik "Tetap Pasang" (Install Anyway).
Untuk Admin IT Sekolah — Metode Kiosk (Device Owner)
PERINGATAN: Metode ini akan menghapus seluruh data di perangkat dan menguncinya sebagai kiosk ujian. Hanya gunakan pada perangkat sekolah yang dikelola tim IT — jangan gunakan pada HP pribadi siswa/guru.
1
Factory Reset Perangkat Hapus seluruh akun Google di perangkat (harus dalam kondisi kosong seperti baru), lalu instal berkas Kiosk APK.
2
Daftarkan Hak Akses via ADB Hubungkan perangkat ke komputer dengan USB Debugging aktif. Ketikkan perintah ini di terminal komputer Anda:
adb shell dpm set-device-owner com.examvan.app.kiosk/com.examvan.app.receiver.MyDeviceAdminReceiver

Instalasi Client Windows

Unduh executable khusus PC / Laptop berbasis Windows 10 & 11

Belum ada installer Windows (.exe) yang tersedia di sistem.

Panduan Aktivasi Windows

1
Jalankan Berkas Installer Ekstrak folder jika berkas berbentuk ZIP, kemudian klik ganda pada file .exe yang diunduh.
2
SmartScreen Bypass Bila sistem mendeteksi proteksi Windows Defender SmartScreen, klik "More Info"/"Info lainnya" lalu pilih "Run anyway"/"Tetap jalankan".
3
Mulai Ujian Aplikasi akan mengaktifkan lockdown engine (menutup akses Alt+Tab, tombol Windows, dan Task Manager) secara otomatis begitu ujian dimulai.

Instalasi Client Linux

Unduh binary portable/AppImage untuk sistem operasi berbasis GNU/Linux

Belum ada installer Linux (.AppImage) yang tersedia di sistem.

Panduan Eksekusi Linux

1
Berikan Hak Akses Eksekusi Buka terminal Anda di lokasi berkas .AppImage diunduh, lalu jalankan perintah:
chmod +x EXAMVAN.AppImage
2
Jalankan Aplikasi Klien Klik ganda pada file atau jalankan dari terminal dengan mengetik: ./EXAMVAN.AppImage.
